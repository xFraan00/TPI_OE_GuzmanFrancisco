## Sistema de Gestión de Materiales y Herramientas para Obras

## Descripción del proyecto

El proyecto consiste en el desarrollo de un prototipo de un sistema para gestionar los materiales y las herramientas utilizados en una empresa de construcción.

Actualmente, el control de los materiales se realiza principalmente de forma visual en cada obra. Cuando el capataz detecta que un material está por agotarse, informa la necesidad al jefe, quien se encarga de gestionar la compra y coordinar la entrega.

El sistema busca mejorar este proceso mediante el registro de materiales, el control del stock por obra y el seguimiento de los movimientos de entrada y salida. De esta manera, se pretende detectar faltantes con anticipación y reducir las demoras ocasionadas por la falta de materiales.

## Objetivo general

Desarrollar un prototipo que permita mejorar el control de materiales y herramientas, facilitando el seguimiento de las existencias y la planificación de las reposiciones en las obras activas.

## Alcance del sistema

El prototipo estará orientado a:

- Registrar materiales y herramientas.
- Consultar las existencias de materiales por obra.
- Registrar movimientos de entrada y salida.
- Identificar faltantes y necesidades de reposición.
- Facilitar el seguimiento de los recursos utilizados en las obras.

## Uso de inteligencia artificial

Durante el desarrollo del proyecto se utilizó ChatGPT como herramienta de apoyo para organizar la documentación, analizar alternativas, mejorar la redacción y elaborar algunos elementos del trabajo.

## Prompts utilizados

A continuación, se presentan algunos ejemplos de las instrucciones utilizadas:

"Ayudame a analizar una empresa constructora como sistema abierto, identificando entradas, procesos, salidas y retroalimentación".

"Revisá este análisis FODA y sugerí modificaciones para evitar repetir fortalezas y oportunidades".

"Ayudame a representar mediante BPMN el proceso de reposición de materiales de una empresa constructora, incluyendo los participantes y las posibles decisiones".

"Revisá la introducción del diccionario de datos y mejorá su redacción manteniendo un lenguaje sencillo".

"Ayudame a organizar la documentación del proyecto y a definir indicadores para evaluar el funcionamiento del sistema".

## Modificaciones realizadas por el estudiante

Las respuestas generadas por ChatGPT fueron revisadas y adaptadas manualmente. Entre las principales modificaciones se encuentran:

Se ajustó el análisis del sistema abierto para diferenciar los recursos que ingresan a la organización de las personas que forman parte de su estructura interna.

Se modificó el análisis FODA para evitar repetir conceptos entre fortalezas y oportunidades.

Se reformuló el plazo de desarrollo del proyecto para establecer un máximo de 12 semanas.

Se adaptaron las descripciones del proceso BPMN según el funcionamiento real de la empresa y las tareas de cada participante.

Se corrigieron y reorganizaron los contenidos del organigrama, el diccionario de datos y las distintas secciones de la documentación.

ChatGPT también se utilizó como apoyo para elaborar inicialmente el gráfico del organigrama. Posteriormente, siguiendo la corrección docente, el gráfico fue rehecho manualmente en diagrams.net.

Las decisiones finales, las revisiones y las modificaciones del contenido fueron realizadas por el estudiante, teniendo en cuenta las características de la empresa y los requisitos del trabajo práctico.
