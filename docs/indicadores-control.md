Indicadores de Control y Estándares de Desempeño

Objetivo

Indicadores de control

1. Exactitud del stock

Se verificará que las existencias registradas coincidan con los movimientos de entrada y salida de materiales.

Estándar esperado: el stock calculado debe coincidir con el resultado de los movimientos registrados durante las pruebas.

2. Registro de movimientos

Se comprobará que las entradas y salidas de materiales queden registradas correctamente.

Estándar esperado: todos los movimientos de prueba deben conservar los datos necesarios para su identificación y seguimiento.

3. Detección de faltantes

Se evaluará si el sistema permite identificar materiales cuya cantidad disponible sea insuficiente para las necesidades de una obra.

Estándar esperado: el sistema debe advertir cuando el stock no alcance para cubrir la cantidad requerida.

4. Asociación con la obra

Se comprobará que cada movimiento esté vinculado con la obra a la que corresponde.

Estándar esperado: todos los movimientos deben estar asociados al material y a la obra correctos.

5. Validación de datos

Se verificará que el sistema rechace cantidades negativas y registros que no contengan los datos obligatorios.

Estándar esperado: los datos inválidos deben ser rechazados y el sistema debe informar el motivo al usuario.

Estándares de desempeño

Para comprobar el funcionamiento del prototipo, se realizarán pruebas con datos simulados de diferentes obras y materiales.

Durante las pruebas se verificará que:

- Las entradas incrementen las existencias y las salidas las disminuyan correctamente.
- No se permita registrar una salida superior al stock disponible.
- Los avisos de faltantes se generen cuando corresponda.
- Los movimientos queden asociados al material y a la obra correctos.
- Los datos inválidos sean rechazados y se informe el motivo al usuario.

Los resultados se registrarán durante las pruebas para identificar errores y realizar las correcciones necesarias.

Alcance de los indicadores

Los estándares definidos son criterios iniciales para evaluar un prototipo académico. Su cumplimiento deberá comprobarse mediante pruebas; no se considera demostrado hasta que estas se ejecuten y documenten.
